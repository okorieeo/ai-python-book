# Backend rules (path-scoped; place at .claude/rules/backend.md)

- Views are thin: parse, call a service, serialize. Logic in `services.py`, reads in `selectors.py` (every selector takes the user).
- Every serializer lists its `fields` explicitly; server-controlled fields are `read_only_fields`.
- API objects are addressed by `public_id`; another user's object is a 404.
- Every endpoint ships with tests: 401, 404 for another user, 403 for a wrong role, 400, happy path, idempotency, query count.
- Before saying a task is done run: `python -m core.review.django_review backend/` and `python manage.py makemigrations --check`.
