# Building AI-Powered Apps — companion code

Code, listings and extended material for the book *Building AI-Powered Apps: From Zero to Production*.

Repository: https://github.com/okorieeo/ai-python-book

```bash
git clone https://github.com/okorieeo/ai-python-book.git
cd ai-python-book
```

## How the repository is organised

- `chapter-NN/code/` — the project files that go with chapter NN.
- `chapter-NN/listings/` — complete listings that the printed chapter refers to but does not print in full.
- `chapter-NN/EXTENDED.md` — (where present) material that was moved out of the print edition.
- `chapter-NN/README.md` — what is in the folder and how to run it.
